Monitor Protocol Reference

AutoDRIVE Race Control Tower exposes monitor APIs for the browser frontend. Browser clients use REST for snapshots and commands, and WebSocket for live status, telemetry, audit, and command streams.

Path Layout

REST clients use /monitor/REST/0.1/... or /monitor/REST/latest/.... WebSocket clients use /monitor/WS/0.1 or /monitor/WS/latest.

Message Shape

REST responses are JSON unless an endpoint returns an MCAP binary download. WebSocket server-to-client and client-to-server messages are JSON text frames. Binary WebSocket client messages are rejected and broadcast as an error event.
