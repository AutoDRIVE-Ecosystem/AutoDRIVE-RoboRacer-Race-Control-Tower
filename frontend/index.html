Select which topics RCT forwards to the cars. Only checked topics are delivered. Restricted topics are not allowed during racing, but they can be enabled for testing or practice. Front Camera can significantly affect performance, so leaving it unchecked is recommended unless you specifically need it.

Topic Access

Configure how much telemetry RCT keeps before a detected collision. When either car's collision count increases, RCT will use this pre-accident window to create an accident bag for review. Including the front camera can use a lot of memory, so it is not recommended unless you need video evidence.

Configure how RCT releases vehicles after a collision decision. When a vehicle receives a penalty, RCT can keep that vehicle's throttle and steering commands filtered to zero for a short restart delay while the other vehicle is released immediately.

SW Analysis

Configure the race win conditions. RCT ends the race when a vehicle reaches the target lap count first, or when the other vehicle reaches the maximum penalty count if that limit is greater than zero.

AutoDRIVE Race Control Tower (RCT) is a WebSocket race-control proxy for the AutoDRIVE RoboRacer simulator. It accepts simulator traffic, forwards vehicle data to configured DevKit bridge instances, rewrites vehicle identifiers for each assigned RoboRacer, and streams connection status back to this browser dashboard.
